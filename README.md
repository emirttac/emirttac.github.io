# emirttac.github.io

Personal portfolio site for [emirttac](https://github.com/emirttac).

**Live:** [https://emirttac.github.io](https://emirttac.github.io)

## Local preview

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

```
index.html
css/styles.css
js/i18n.js
js/main.js
```

Static site — no build step. Push to `main` to publish via GitHub Pages.
