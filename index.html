Selected work

Software I've built from the first line to the installer

Open a project to see the problem it solves and how it's built. The code is one click away.

  • Many overlays inject code into the game process. Mars doesn't: it reads frame data from Windows kernel graphics events (ETW) instead. What started as an FPS counter became a full control panel — seven HUD layouts, a game library across five launchers with per-game stats, optional GPU overclocking for NVIDIA, AMD and Intel Arc, and a fan-control beta.

    • FPS comes from Windows ETW events, filtered to the foreground game and de-duplicated across three graphics providers (DXGI, Direct3D 9, DxgKrnl). No DLL injection.
    • Built to fail safe: overclock values are hard-clamped (imported profiles and AI suggestions included), bad sensor data falls back to stock clocks, and an exit or crash restores driver defaults.
    • Production-minded: an Inno Setup installer that handles .NET and VC++ prerequisites, unit tests around the risky logic, no telemetry, crash reports redacted before you share them, and 10 UI languages.
    View code on GitHub

  • Most “cleaner” tools either hide what they change or apply dozens of risky tweaks in one click. WinCleaner is built around visibility and control: every tweak, service and app lives in an auditable JSON catalog, carries a risk level, and is filtered by Windows build. Currently in public beta.

    • Four risk levels — Safe, Caution, Dangerous, Blocked. Blocked items, like critical system services, can't be run at all; dangerous ones need an explicit opt-in plus a confirmation dialog.
    • Reversible where possible: a System Restore point before changes, a session change log and a global Undo backed by a persistent journal.
    • Layered architecture (WPF/MVVM → Core → Data) over a catalog of 92 tweaks, 28 services and 46 AppX packages, six presets, and unit tests that keep all 8 languages in sync.
    View code on GitHub

  • A small tray app for Stream Deck–style workflows: assign a key — numpad included — to a video, audio file or image, press it, and the media opens fullscreen on top of everything else. A native PyQt6 app rather than Electron, so it stays light.

    • Global hotkeys that work from any app, ESC or a click to dismiss, and a JSON config with a settings window on top.
    • Packaged for people who don't code: PyInstaller bundles everything, and the Inno Setup installer needs no Python, no console windows and no downloads.
    • Available in English, German, Turkish and Chinese, with the language picked automatically from the system.
    View code on GitHub

  • An image-enhancement desktop app where nothing leaves your machine: no cloud API, no analytics. A fast FSRCNN model is bundled; Real-ESRGAN through ONNX Runtime is available when you need better text, line art and faces.

    • Overlapping-tile processing keeps large photos stable on modest hardware; transparency is preserved; exports to PNG, JPEG and WebP.
    • Hardware-aware: a startup check scores the machine, and Real-ESRGAN uses CoreML on Apple Silicon or DirectML/CUDA on Windows when available, with CPU as the fallback.
    • Ships for two platforms — a Windows installer and a macOS DMG — with a pluggable model-backend design and 8 UI languages.
    View code on GitHub

  • A lightweight in-game FPS and hardware monitor built on Windows kernel tracing, with no process injection. It reports FPS, 1% lows, frametime, CPU/GPU temperature and clocks, and RAM/VRAM, in four overlay styles.

    • Four overlay themes, drag-or-grid positioning, and a color picker written from scratch with trigonometry on WPF primitives.
    • Moved its sensor layer to LibreHardwareMonitor for deeper, more robust readings, and expanded the metrics to 1% low, frametime, clocks and VRAM.
    • An Inno Setup installer that quietly installs the .NET 8 and VC++ runtimes, and a UI in 8 languages.
    View code on GitHub

  • A small, separate repository that holds GPU overclock presets as JSON. Mars fetches it only when you ask for suggestions, so presets can be improved without releasing a new app version.

    • Data lives apart from code, so the catalog and the app are versioned independently.
    • Fetched on demand only, and anything it suggests still passes through Mars' hard overclock limits.
    • Plain, reviewable JSON — easy to audit and to extend through pull requests.
    View code on GitHub

About

Emir Tuğra Ataç

I'm Emir Tuğra Ataç, a software developer focused on Windows and desktop applications. I enjoy the parts of a product users never see: reading frame data straight from the kernel, writing safety limits that fail closed, and building installers that handle every prerequisite so setup is just Next, Next, Finish.

A few habits run through all my projects: they work locally and respect privacy, they explain what they're about to do before they do it, the risky logic is covered by tests, and they speak the user's language — Mars ships in 10. All the code is public on GitHub, so you can read it instead of taking my word for it.

I've been publishing since 2023, and since 2024 I've been building a presence on YouTube as a video creator — shipping content, engaging with the community, and sharing what I learn in public.
